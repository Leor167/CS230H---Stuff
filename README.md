# CS230H---Stuff
My Project for CS230H

Project Pitch:

My idea is to make a match making lobby and game server for players to connect to.

The project criteria are that it has to be able to naturally incorporate a linked data structure, handle multiple concurrent control flows (multithreading), and connect over a network (client-server architecture).

The idea is that actually match making queue is a linked data structure. 
Multiple users can queue concurrently connecting to the game server.
